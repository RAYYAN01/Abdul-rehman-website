# Bangalore Luxe Estates

A premium Next.js 15 website for a luxury real estate brand in Bangalore, built with TypeScript, Tailwind CSS, Framer Motion, GSAP-ready structure, Three.js effects, and optimized SEO.

## Features
- Modern luxury homepage, About, and Contact pages
- Hero interactions, glassmorphism, premium gradients, and floating cards
- Property discovery, testimonials, premium CTA sections
- Advanced SEO with metadata, Open Graph, Twitter cards, sitemap, and robots.txt
- Lead capture form with Supabase-ready API route
- Fully responsive mobile-first design

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000`

## Production Notes
- Configure `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` for lead capture.
- Deploy on Vercel for optimal performance and SEO.
